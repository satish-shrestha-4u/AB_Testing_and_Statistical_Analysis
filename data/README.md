# Data

This folder contains the experiment data files used for the Eniac homepage button A/B test.

The dataset includes separate CSV files for each button version tested in the experiment.

## Files

- `eniac_a.csv` — data for Version A: SHOP NOW, white button
- `eniac_b.csv` — data for Version B: SHOP NOW, red button
- `eniac_c.csv` — data for Version C: SEE DEALS, white button
- `eniac_d.csv` — data for Version D: SEE DEALS, red button

These files are used in the notebook to calculate click-through rates, build contingency tables, and perform statistical tests.
