# Supporting Notebooks

This folder contains supporting notebooks used during the development of the A/B testing and statistical analysis project.

These notebooks include refresher exercises, statistical foundations, hypothesis testing practice, and earlier versions of the Eniac A/B test analysis.

The final cleaned project notebook is stored in:

`notebooks/eniac_ab_test_analysis_complete.ipynb`

## Files

- `01_for_loops_and_sampling_refresher.ipynb` — loop refresher used before sampling and statistical simulations
- `02_sampling_loop_practice.ipynb` — practice with sampling, repeated sampling, and loop-based calculations
- `03_central_limit_theorem.ipynb` — Central Limit Theorem and sampling distributions
- `04_confidence_intervals.ipynb` — confidence interval estimation
- `05_one_sample_t_test.ipynb` — one-sample hypothesis testing
- `06_two_sample_t_test.ipynb` — two-sample hypothesis testing
- `07_chi_square_test_methodology.ipynb` — chi-square test methodology and interpretation
- `08_eniac_final_decision_making.ipynb` — Final Decision-Making for the Eniac homepage button experiment
- `09_eniac_ab_test_chi_square_analysis.ipynb` — practical chi-square analysis of the Eniac A/B test
